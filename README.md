# 인조잔디의 모든 것 — 백링크 허브 설치 안내서

네이버 블로그·티스토리 글을 모아 보여 주는 허브 사이트입니다. 구글 로봇이 이 허브에 들렀다가 카드 링크를 따라 **네이버 원문**을 찾아가게 만드는 것이 목적입니다.

```
1. 허브 사이트 개설      ← 내가 한 번 (이 안내서 1~6)
2. 글 목록 자동 등록      ← 매일 자동 (오전 6시 17분)
3. 구글에 허브 알리기     ← 내가 한 번 (이 안내서 7~8)
4. 구글 로봇이 허브 방문  ← 구글
5. 네이버 원문이 구글에 노출 ← 구글
```

> 중국에서는 GitHub·구글 접속에 VPN이 필요합니다. 전부 VPN을 켠 상태에서 진행하세요.

---

## 준비물

- 이 폴더(압축 파일 `turf-hub.zip`을 푼 것)
- 이메일 주소 (GitHub 가입용)
- 구글 계정 (서치 콘솔용, 티스토리 때 쓴 계정)

---

## 1. GitHub 가입 (5분)

1. https://github.com 접속 → **Sign up**
2. 이메일, 비밀번호, **아이디(Username)** 입력
3. 이메일로 온 인증 코드 입력

아이디는 사이트 주소가 됩니다. 예) 아이디가 `turfall`이면 사이트 주소는 `https://turfall.github.io`

## 2. 저장소(사이트 폴더) 만들기 (2분)

1. 오른쪽 위 **+** → **New repository**
2. **Repository name**에 `아이디.github.io` 를 정확히 입력 (예: `turfall.github.io`)
3. **Public** 선택 (무료 사이트는 공개 저장소여야 함)
4. **Create repository**

## 3. 파일 올리기 (3분)

1. 방금 만든 저장소 화면에서 **uploading an existing file** 글자 클릭
2. 압축을 푼 `turf-hub` 폴더 **안의 내용 전부**(`config.json`, `scripts`, `static`, `tests`, `.github`, `README.md`, `.gitignore`)를 끌어다 놓기
   - `.github` 폴더가 꼭 들어가야 합니다. 이것이 매일 자동 실행 설정입니다.
3. 아래 **Commit changes** 클릭

## 4. 사이트 주소 적기 (1분)

1. 저장소에서 `config.json` 클릭 → 연필 모양(Edit) 클릭
2. 이 줄을 내 주소로 바꾸기
   ```
   "site_url": "https://YOUR-GITHUB-ID.github.io",
   ```
   → 예) `"site_url": "https://turfall.github.io",`
3. **Commit changes**

## 5. 사이트 기능 켜기 (2분)

1. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
2. **Source**를 **GitHub Actions**로 선택
3. 왼쪽 **Actions** → **General** → 맨 아래 **Workflow permissions**에서 **Read and write permissions** 선택 → **Save**

## 6. 첫 실행 — 예전 글 전체 가져오기 (5분)

1. 저장소 위쪽 **Actions** 탭
2. 왼쪽 **허브 자동 갱신** → 오른쪽 **Run workflow**
3. **네이버 예전 글 전체 목록까지 가져오기** 칸에 체크 → 초록 **Run workflow**
4. 노란 점이 초록 체크로 바뀔 때까지 기다리기 (몇 분)
5. `https://아이디.github.io` 접속 → 허브 화면 확인

**결과 확인 방법:** Actions 실행 기록에서 **글 수집** 단계를 누르면 블로그별로 가져온 글 수가 나옵니다. "실패"라고 나오는 블로그가 있으면 그 화면을 캡처해서 Claude에게 보여 주세요.

이후로는 **매일 오전 6시 17분(한국 시간)에 자동**으로 새 글을 반영합니다.

## 7. 구글 서치 콘솔 등록 (10분, 한 번만)

1. https://search.google.com/search-console → 왼쪽 위 속성 선택 → **속성 추가**
2. 오른쪽 **URL 접두어**에 `https://아이디.github.io` 입력 → 계속
3. **HTML 태그** 선택 → 나온 태그에서 `content="..."` 안의 값만 복사
   - 예) `<meta name="google-site-verification" content="abc123XYZ">` → `abc123XYZ`
4. GitHub 저장소의 `config.json` 편집 → 이 줄에 붙여 넣기
   ```
   "google_site_verification": "abc123XYZ",
   ```
5. **Commit changes** → Actions 탭에서 실행이 초록 체크가 될 때까지 기다리기 (1~2분, 자동으로 다시 만들어짐)
6. 서치 콘솔로 돌아가 **확인**
7. 왼쪽 **Sitemaps** → `sitemap.xml` 입력 → **제출**

## 8. 네이버 서치어드바이저 등록 (10분, 한 번만)

1. https://searchadvisor.naver.com → 웹마스터 도구 → 사이트 등록 → `https://아이디.github.io`
2. **HTML 태그** 방식 선택 → `content="..."` 값만 복사
3. `config.json`의 `"naver_site_verification": ""` 칸에 붙여 넣기 → Commit → 실행 끝날 때까지 기다리기
4. 소유확인 → **요청 → 사이트맵 제출**에 `https://아이디.github.io/sitemap.xml` 입력

## 효과 측정 (4~8주)

현재 설정은 **모든 글을 허브에 싣습니다**(`"holdout_percent": 0`). 그래서 효과는 "허브 시작 전과 후"를 비교해서 봅니다.

1. **허브를 켜기 전에** 구글에서 몇몇 글 제목을 검색해 지금 뜨는지 적어 둡니다 (시작 전 기록).
2. 저장소 `data/measure.csv` → 오른쪽 **Download** → 엑셀로 열기
3. 매주 한 번, 확인할 글의 **구글 검색** 칸(파란 "검색")을 누르기 → 그 글 제목으로 구글 검색이 열림
   - VPN을 켜고, 가능하면 브라우저 시크릿 창에서 보세요.
   - 글이 많으면 표본만: 최근 글 위주로 20~40개
4. 검색 결과에 네이버 원문이 나오면 **구글 노출 확인일** 칸에 날짜 입력 (예: 2026-11-20)
5. 저장 → 엑셀이 "CSV 형식으로 저장하면 일부 기능이 손실될 수 있다"고 물으면 **예** → 저장소에 같은 이름(`measure.csv`)으로 다시 올리기
   - 엑셀 기본 CSV, "CSV UTF-8" 어느 형식으로 저장해도 읽힙니다.
   - 다시 만들어도 적어 둔 날짜는 지워지지 않습니다.

전후 비교는 구글 자체의 변화와 허브 효과가 섞일 수 있어서, 허브만의 효과를 정확히 가려내고 싶으면 `"holdout_percent"`를 `30`으로 바꾸면 됩니다. 그러면 글의 약 30%를 허브에서 빼 두고 두 그룹을 비교합니다.

## 자주 바꾸는 설정 (`config.json`)

| 항목 | 뜻 | 예 |
|---|---|---|
| `site_title` | 사이트 이름(한 줄 소개) | `인조잔디의 모든 것` |
| `site_tagline` | 이름 아래 설명 | `인조잔디 현장 3년, 제조사 이사가 쓴 글 모음` |
| `author`, `affiliation` | 쓴 사람, 소속 (아래쪽에 표시) | `홍길동`, `주목씨지알 이사` |
| `naver_blog_ids` | 수집할 네이버 블로그 ID | `["jmcgr", "sumturf"]` |
| `tistory_blogs` | 수집할 티스토리 이름 | `["jmcgr"]` |
| `related_sites` | 홈의 "함께 보기" 링크 | 회사 시공실적 게시판 |
| `category_slugs` | 카테고리 이름 → 영어 주소 | `"반려견 인조잔디": "pet"` |
| `featured.count` | 대표 글 개수 | `7` |
| `featured.keywords` | 대표 글로 먼저 뽑을 단어 | `["인조잔디", "배수"]` |
| `featured.pinned_urls` | 항상 맨 앞에 고정할 글 주소 | 네이버 글 주소 |
| `excerpt_length` | 카드 요약 글자 수 (짧게 유지) | `180` |
| `measurement.holdout_percent` | 비교군 비율(%) | `30` |

`category_slugs`에 없는 카테고리는 `c-1a2b3c` 같은 주소가 자동으로 붙습니다. 실행 기록 마지막 줄에 "주소 이름이 정해지지 않은 카테고리" 목록이 나오니, 영어 이름을 정해 추가하면 됩니다. **한 번 정한 주소는 바꾸지 않는 것이 좋습니다.**

## 이 허브가 하지 않는 것 (일부러)

- 원문 본문 복사 → 카드에는 제목과 약 180자 요약만
- 글마다 얇은 페이지 만들기 → 홈·카테고리·월별 목록만
- 남의 블로그 링크 → 내 블로그와 회사 글만
- 구글 Indexing API 사용 → 채용 공고·생방송 전용이라 쓰지 않음

## 알려진 한계

- 네이버 RSS는 최근 약 50개 글만 보여 줍니다. 그 이전 글은 6번 첫 실행의 "전체 목록 가져오기"로 가져옵니다. 이 전체 목록 기능은 **네이버 공식 기능이 아니라서** 네이버가 바꾸면 멈출 수 있습니다. 멈춰도 RSS 글과 이미 저장된 글은 그대로 남습니다.
- 네이버·티스토리가 GitHub 서버의 접속을 막는지는 **첫 실행에서 확인**해야 합니다.
- 티스토리 RSS에는 현재 글 10개가 나옵니다(마지막 글 2022년 12월).
- 공개 저장소는 60일간 변화가 없으면 예약 실행이 꺼집니다. 이 허브는 매일 실행 기록을 저장하므로 꺼지지 않게 설계했습니다.
- 회사 홈페이지(아임웹) 시공실적 게시판 글은 1단계에서는 "함께 보기" 링크 하나로만 연결합니다.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `config.json` | 설정 (이것만 고치면 됨) |
| `scripts/fetch.py` | 글 수집 (RSS + 예전 글 전체 목록) |
| `scripts/build.py` | 페이지·사이트맵·robots.txt·측정표 만들기 |
| `scripts/common.py` | 공용 도구 |
| `static/style.css` | 화면 모양 |
| `.github/workflows/hub.yml` | 매일 자동 실행 설정 |
| `data/` | 수집된 글 목록, 측정표 (자동 생성) |
| `tests/` | 시험 코드 (`python -m pytest tests`) |
